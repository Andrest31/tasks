# Personal Roadmap

Минималистичный персональный roadmap-редактор на Next.js + React Flow.

## Запуск на macOS

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Управление

- Указатель: выбор и рамка множественного выделения.
- Блок: выберите инструмент и кликните по холсту.
- Текст: выберите инструмент и кликните по холсту.
- Стрелка: выберите инструмент и протяните соединение между точками блоков.
- Концы стрелок автоматически переходят на подходящую сторону блока при его перемещении.
- Один клик по блоку: открыть подробности.
- Двойной клик по названию блока: переименовать прямо на холсте.
- Двойной клик по тексту: изменить текст.
- В редакторе текста Enter сохраняет, Shift+Enter добавляет новую строку.
- Delete / Backspace: удалить все выделенные объекты.
- Cmd/Shift + клик: добавить объект к выделению.

## Сохранение

Roadmap автоматически сохраняется в `localStorage`: блоки, тексты, стрелки, позиции, завершённость и положение/масштаб холста восстанавливаются после перезагрузки страницы.

Важно: `localStorage` привязан к конкретному браузеру и домену. После деплоя на Vercel данные будут сохраняться на этом Vercel-домене, но не синхронизируются между разными браузерами или устройствами.

## Деплой на Vercel

Проект не требует сервера или базы данных. Его можно импортировать из GitHub в Vercel как обычный Next.js-проект. Build command: `npm run build`.
